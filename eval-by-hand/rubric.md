# Rubric for the reply grader

The grader reads this file and the draft replies, and nothing else. It does
not know the support policy unless this file tells it. You write the criteria,
by hand. Claude cannot edit this file.

Write each criterion so that a careful stranger could apply it the same way
twice. Say what makes a reply FAIL as well as what makes it pass.

STARTER TEXT: replace everything below this line with your own criteria.

A reply passes if it is helpful, polite and correct.
