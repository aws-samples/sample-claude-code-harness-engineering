# Evals by hand

A one-hour, hands-on module for people who have used Claude Code a little.
No coding is needed.

You will build a small eval the way practitioners do: read real-looking
outputs, label them by hand, write a rubric in plain English, let Claude
grade with your rubric, and then work through every place where the grader
and you disagree. You edit, it grades again, and you see whether your rubric
holds up on cases it has never seen.

Claude is the grader and a sounding board. The labels, the rubric and the
rulings are yours, and this folder is set up so that Claude cannot make them
for you.

**You need:** Claude Code 2.1.218 or later, signed in (`claude update`
brings it up to date), Python 3.9 or later (nothing to install), two
terminal windows and a plain-text editor.

**Start here:** open `GUIDE.md` and follow it from the top. It is a Markdown
file: if your editor shows it as plain text, the asterisks (**) and
backticks around words are formatting, and you do not type them.

Everything in the data folder is fictional.
