# Harness Engineering workshop

- `appointment_reminders/` is the service the PRs change. Its README is the tour.
- `my-work/` holds the participant's own files. The TODOs are theirs to answer.
- `guide/` holds the lab's instructions, the same pages the participant reads.
- `docs/team-rules.md` is the brief. `data/review-prs/` holds the PRs.
- `./lab` runs everything. `scripts/` holds the checks, reviewer runner, eval and human gate.
- Python 3.11+, `uv` only, `from __future__ import annotations`.
