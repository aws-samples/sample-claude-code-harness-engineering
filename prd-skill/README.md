# Write a skill that drafts PRDs

A one-hour hands-on exercise with Claude Code, for one person working alone.

You teach Claude Code how your team writes a product requirements document (PRD). You do it by writing a skill by hand, reviewing the drafts it produces against your own team's rules, and improving the skill until the drafts come out the way your team wants them.

You need:

- Claude Code 2.1.218 or later, signed in (`claude update` brings it up to date)
- Python 3.9 or later (nothing to install beyond Python itself)
- two terminal windows
- a plain-text editor

To open a file: in a cloud or desktop code editor, click it in the file list. On macOS you can also type `open -e GUIDE.md` in a terminal, and on Windows `notepad GUIDE.md`.

The guide is a Markdown file. If your editor shows it as plain text, the asterisks (**) and backticks around words are formatting. Do not type them: where the guide shows a command between backticks, type only the command.

You do not need to write any code.

**Start here:** open `GUIDE.md` and follow it from the top.

Everything in the `briefs` folder is made up for this exercise.
