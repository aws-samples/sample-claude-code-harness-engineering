# Harness Engineering workshop

The instructions are in [`guide/part-1.md`](guide/part-1.md) and [`guide/part-2.md`](guide/part-2.md), and match the workshop pages.

To start, run `claude` in one terminal and `./lab next` in another.

Optionally, if you want to interact with your AWS account, install the Agent Toolkit for AWS by following its [quick start](https://docs.aws.amazon.com/agent-toolkit/latest/userguide/quick-start.html). This repo turns on its `aws-core` plugin in `.claude/settings.json`.
